The MarsAI MCP server ([MarsAI Connect](/cloud/run-in-the-cloud/cloud-mcp))
enables Codex to use the MarsAI capabilities your organization has made
available to you: Gmail read/search, Calendar list/create, Drive search/read,
Gmail draft creation, shared MCP connections such as Notion, Linear, Slack,
Stripe, Exa, and Context7, shared skills, and MarsAI Cloud resources like
skills, plugins, Collections, workers, members, roles, teams, and LLM
providers. The server exposes only `search_capabilities` and
`execute_capability`, so Codex searches what you can access and runs exact
capability names instead of loading hundreds of tool definitions into context.

## Server URL

```text
https://api.mars.example.com/mcp/agent
```

marsai.click does not run a hosted Den, so there is no public endpoint: use the
`/mcp/agent` URL on the API origin of your [self-hosted Den](/start-here/self-host)
(`api.mars.example.com` above is a placeholder). OAuth sign-in uses your
account on that Den, and the organization you pick is pinned into the token.

## Setup

1. Add MarsAI Connect:

   ```sh
   codex mcp add mars --url https://api.mars.example.com/mcp/agent
   ```

2. Log in and finish the browser sign-in:

   ```sh
   codex mcp login mars
   ```

In the Codex desktop app, open `codex://settings/connections` and paste the
server URL there instead.

## Switch organizations

Log out, then log in again and choose the organization you want:

```sh
codex mcp logout mars
codex mcp login mars
```

<Note>
This is a setup guide. These steps match MarsAI Connect's OAuth profile:
HTTPS or HTTP loopback callbacks, PKCE S256, and dynamic client registration
fallback. Codex is listed as setup only because native proof is not complete.
See the
[client support status](/cloud/run-in-the-cloud/cloud-mcp#client-support-status)
table.
</Note>
